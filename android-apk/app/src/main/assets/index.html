Features

          
    
            
  • Quanta Lab tracker — search, difficulty & status filters, per-problem rich-text notes and saved code
    • 
            
  • Full problem statements from the online database, cached on this device and bundled for offline reading
    • 
            
  • Code Lab with Monaco editor and real compile & run for Java, JavaScript, Python, C and C++
    • 
            
  • Runs automatically fall back to a second runner when the first cannot answer
    • 
            
  • Star problems for revision and track solved progress per language
    • 
            
  • Three themes — Emerald Night, Pearl Light and Ember — plus per-language editor colors
    • 
            
  • Notes workspace with rich text, word count and export to Quanta Lab or text/HTML files
    • 
            
  • Works offline — statements, notes, code and stats stay on this device (localStorage)
    • 
            
  • Hosted catalog sync — statements fetched online are written back to the database for other devices
    • 
            
  • Export a full JSON backup of everything, plus custom API and runner addresses with connection tests
    •
